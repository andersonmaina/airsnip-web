Airsnip is a CLI-first code sharing tool for developer teams. This repository contains the modern, high-performance landing page built with React, TypeScript, and Vite.

---

## Getting Started

### 1. Install with node.js
```bash
npm install -g airsnip
cd Landing
```

### 2. Authenticate - ontime
```bash
airsnip login
```

### 5. See docs/help for usage
```bash
airsnip help
```
### 6. Example - (push a file)
```bash
airsnip init
airsnip push file mp_project/src/components/footer/index.ts --tag portfolio_website_footer
```
